# Hi, I'm Leonardo Gaspar Mejía

Robotics Engineering Student at Universidad Autónoma de Aguascalientes | Robotics Software, Embedded Systems & IoT

I'm a Robotics Engineering student interested in the intersection of robotics, software, and control systems. I enjoy building my own projects, exploring different approaches to engineering problems, and developing tools that help me better understand how robotic systems work.

Most of my work focuses on Python, embedded programming, robot kinematics, and automation. I'm particularly interested in creating modular and reusable software, from mathematical tools for robotics to intelligent systems that connect different technologies.

## Current Work & Focus

- **Robotics Software:** Developing educational tools in Python for robot kinematics, coordinate transformations, and 3D visualization.
- **A.R.I.A.:** Building a personal assistant with a modular architecture, structured memory, tool execution, and validation mechanisms.
- **IoT & Embedded Systems:** Exploring ESP32, Arduino, C/C++, FreeRTOS, and the integration of software with physical hardware.
- **Control & Industrial Automation:** Working with digital control systems, PID controllers, PLCs, HMIs, and industrial communication protocols.
